# 💳 Credit Ledger (크레딧 장부)

여러 API의 남은 크레딧과 "방금 얼마 썼는지"를 실리태번 안에서 한눈에 보는 확장입니다.

- 입력창 위에 한 줄 요약: `💳 Vertex · 방금 $0.0123 · 남은 ~$287.39`
- 지갑(API 계정)별 남은 잔액, 오늘/이번 달 사용액, 최근 사용 기록
- 다른 확장이 몰래 보내는 요청(요약 등)도 함께 집계

## API별 계산 방식

| 종류 | 남은 잔액 | "방금 쓴 양" | 서버 플러그인 |
|---|---|---|---|
| Google Vertex AI | 처음 입력한 잔액에서 자동 차감 (추정) | 토큰 수 × 단가표 | 필요 없음 |
| Google AI Studio | 위와 같음 | 토큰 수 × 단가표 | 필요 없음 |
| DeepSeek 공식 | **실제 잔액 조회** | 잔액 변화량 | 필요 |
| 중국 프록시 (NewAPI/OneAPI 계열) | **실제 잔액 조회** | 잔액 변화량 | 필요 |
| 기타 | 입력한 잔액에서 차감 | 토큰 수 × 단가표 | 필요 없음 |

- Vertex는 구글이 잔액을 실시간으로 알려주지 않아서 **추정치**예요. 가끔 구글 클라우드 콘솔에서 실제 잔액을 보고 **"잔액 보정"** 버튼으로 맞춰주세요.
- 토큰 수는 **스트리밍을 켰을 때** 구글이 보내주는 정확한 값을 써요. 스트리밍을 끄면 실리태번 토큰 계산기로 추정해요(≈ 표시, 생각 토큰은 빠짐).
- 단가표의 기본값은 참고용이에요. 구글 요금 페이지에서 확인하고 고쳐주세요.
- 프록시에서 여러 번 연달아 보내면 "3회 합계 ¥0.15"처럼 묶어서 보여줘요 (조회는 지갑당 1분에 최대 1번).

## 보안

- **아이디/비밀번호는 받지 않아요.** 새로 API 키를 입력하는 칸도 없어요.
- 잔액 조회는 서버 플러그인이 **실리태번에 이미 저장된 키**를 서버 안에서만 꺼내 써요. 키 값은 브라우저로 나오지 않아요 (화면엔 이름과 끝 3글자만 보여요).
- 키는 **그 키가 연결된 주소로만** 보내요:
  - DeepSeek 키 → `api.deepseek.com`만
  - 사용자 지정(Custom) 키 → 실리태번 연결 설정에 저장된 주소만. 키가 여러 개면 지갑마다 어떤 키인지 직접 골라야 해요.
  - 프록시 프리셋 → 그 프리셋 주소만
  - Google/Vertex/OpenAI/Claude 키는 **아예 읽지 않아요.**
- https 주소만, 리다이렉트 거부, 읽기 전용 조회만 해요. 결제·키 변경 같은 기능은 없어요.
- 서버가 직접 **같은 대상은 30초에 1번**으로 조회를 막아요. 프록시 계정에 무리가 가지 않게요.
- 외부 서버, 추적 기능 없음.

## 설치

### 1. 확장 (화면 부분) — 모든 사람

실리태번 → 확장(블록 아이콘) → **Install extension** → 아래 주소 붙여넣기.

```
https://github.com/kkang1122716/SillyTavern-CreditLedger
```

Vertex / AI Studio만 쓸 거면 여기까지만 하면 돼요.

### 2. 서버 플러그인 — DeepSeek·프록시 실제 잔액을 보고 싶을 때만

VPS 터미널에서 **딱 한 번** 아래를 실행해요 (`~/SillyTavern`은 실리태번 폴더 위치에 맞게 바꿔주세요).

```bash
cd ~/SillyTavern/plugins
git clone --depth 1 https://github.com/kkang1122716/SillyTavern-CreditLedger cl-tmp
cp -r cl-tmp/server-plugin/credit-ledger ./credit-ledger
rm -rf cl-tmp
```

그다음 `~/SillyTavern/config.yaml`에서

```yaml
enableServerPlugins: true
```

로 바꾸고 실리태번을 재시작해요. 터미널에 `[credit-ledger] loaded`가 보이면 성공이에요.

> ⚠️ `enableServerPlugins: true`는 `plugins` 폴더 안의 **모든** 플러그인을 켜요. 그 폴더에 모르는 게 있다면 먼저 확인해주세요.

### 3. 지갑 만들기

1. 실리태번에서 평소처럼 API에 연결해요.
2. 확장 패널 → 💳 크레딧 장부 → **"지금 연결된 API로 추가"**
3. 이름을 정하고:
   - Vertex: 지금 남은 잔액 입력 (콘솔 → 결제 → 크레딧에서 확인)
   - 프록시: "잔액 조회에 쓸 키"에서 **그 프록시의 키**를 골라요
4. 저장. 프록시/DeepSeek는 바로 잔액을 조회해요.

### 같은 계정을 여러 주소로 쓰는 경우 (예: 클라우드플레어 워커)

직접 만든 클라우드플레어 워커처럼 **중간에서 전달만 하는 주소**가 실제로는 같은 Vertex 계정을 쓴다면, 지갑을 따로 만들지 마세요. 따로 만들면 같은 돈이 두 번 계산돼요.

대신 Vertex 지갑 → **편집** → **"같은 계정으로 계산할 다른 주소"**에 워커 주소를 넣어주세요. 그 주소로 보낸 요청도 Vertex 지갑에서 빠지고, 예전 기록도 그 지갑으로 옮겨져요.

> 개인 워커 주소는 비밀번호처럼 다뤄주세요. 이 확장은 그 주소를 실리태번 설정 안에만 저장하고 어디에도 보내지 않아요.

연결된 지갑이 없는 요청은 "최근 사용 기록"에 노란색으로 표시되고, 거기서 "지갑 만들기"를 누를 수 있어요.

## 지우기

- 확장: 확장 관리에서 삭제
- 플러그인: `plugins/credit-ledger` 폴더 삭제 후 재시작

API 키나 실리태번 연결 설정은 전혀 건드리지 않아서, 지워도 원래대로예요.
